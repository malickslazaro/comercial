# Diseño WTG
Identidad estable: logo real de marca/wtg.png, violeta #4435ED, blanco, tinta oscura y grises. Máximo tres tamaños principales, composición editorial, espacio, CTA principal y móvil legible.

Las hojas CSS se extrajeron de las referencias WTG/COIIAR, Ujo, Audidat y de la copia local de Suderow Fernández. Contienen solo estilos, sin propuestas ni cifras de clientes. La web de Suderow no respondió durante esta preparación: referencia local, no verificación del estado actual publicado.

El motor usa componentes comunes y permite elegir variante con `public.design`. No debe inventarse otra marca por cliente. Antes de publicar revisa visualmente móvil y escritorio con navegador; los checks automáticos no sustituyen esta revisión. Fotografías y logos de terceros solo con activos autorizados.
